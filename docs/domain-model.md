# 折叠房跨境配置交付 · 领域模型

版本 1。本文档定义模块化折叠房屋出口业务的共享语言、流程记录与必须由系统强制的不变量。
配套合约见 `contracts/ledger.schema.json`，贯穿全流程的虚构样例见 `fixtures/ledger.json`。

## 1. 目标

海外服务站扫描任意一座折叠房的序列号，必须能回答：

- 它是哪一种**产品族与户型**（如双翼房、太空舱）；
- 采用哪种**电气制式**、**防风抗震等级**、**内装方案**与**智能模块**；
- 每个决定是**谁、在什么时候、依据什么**做出的；
- 从询盘到保修的**完整事件链**与当前责任归属。

序列号是数字线程的入口，而不是只能定位到"销售最后一次修改的报价"。

## 2. 术语

| 术语 | 含义 |
| --- | --- |
| 产品族 product family | 双翼房、太空舱等可折叠出口房型。 |
| 模块 module | 可被多个产品族复用的组成单元，如电气包、智能中控、结构加强件、内装套件。 |
| 选项 option | 模块下供选择的规格，如电气包选项 `230V/50Hz·CE` 与 `120V/240V/60Hz·UL`。每个选项自带单价、重量、交期与适用市场。 |
| 配置版本 configuration revision | 一次完整的工程配置快照：模块选项清单 + 派生价格/重量/交期 + 适用证书。版本号单调递增，不可改写。 |
| 签署版本 signed revision | 经客户与工程双方确认、后续制造与验收均以此为准的配置版本。 |
| 冻结点 freeze point | 流程中禁止静默切换版本的关卡：**投产**（开工）与**装柜**（装箱封箱）。 |
| 产能槽 capacity slot | 模块在某时间窗内的已确认可供应数量，由供应方确认后可被订单锁定。 |
| 产能锁 capacity lock | 订单对产能槽中数量的占用；多张订单争抢同一模块时，先确认者先得。 |
| 序列号 serial number | 单座房屋的唯一标识，在质检环节打刻并贯穿后续全部记录。 |
| 批次 production batch | 同一配置版本一次投产的一组房屋；每座房屋在质检时获得序列号并归属批次。 |
| 发运批次 shipment | 一次实际发运的装箱集合；一张订单可分多个发运批次（分批发运）。 |
| 事件 event | 流程中任何一次状态推进或决定，带时间戳、执行角色、责任人与依据，只追加、不改写。 |

## 3. 参与者与职责

- **客户 customer**：提出询盘、确认报价与签署版本、在目的地逐项验收。
- **销售 sales**：维护询盘与多币种报价；报价失效后必须重新报价。
- **工程 engineering**：出具配置版本，评估每次配置变更对部件、价格、重量、交期的影响。
- **合规 compliance**：按目的国要求评审证书，控制证书的访问范围。
- **采购 procurement**：依据已确认产能下达采购，管理模块供应。
- **供应商 supplier**：确认产能、供货，对来料缺陷负责。
- **工厂质检 QC**：投产、质检判定、打刻序列号、折叠装箱。
- **物流 logistics**：装柜、海运、目的港与分批安排。
- **海外服务站 service station**：清关协调、现场展开、离线安装回传、验收支持与保修处理。

每次决定都通过事件的 `actor`（自然人/工号）、`role`（上述角色）、`decided_by`（决定人）留痕，
用于事后从序列号重现责任归属。

## 4. 配置模型

配置版本由模块选项构成，并派生四类关键属性：

1. **电气制式**：电压/频率/插头与认证体系，必须与目的国匹配（如 230V/50Hz CE 对 120V/240V/60Hz UL）。
2. **防风抗震等级**：结构模块决定的抗风与抗震评级，必须满足目的国准入要求。
3. **内装**：地面、墙面、厨卫等内装套件选项。
4. **智能模块**：中控、能源、安防等可选项，受关键芯片/模块供应约束，是产能争抢的高发点。

配置版本的汇总价格与重量必须等于全部所选选项之和（校验器强制）。
配置版本一旦创建即不可变；任何修改产生新版本，并附**变更影响单**。

## 5. 端到端流程与连续记录

每座房屋的主记录是一条只追加的事件链，阶段固定如下，允许在阶段内产生多条事件与异常：

1. **询盘 inquiry**：目的国、数量、初步需求。
2. **报价 quotation**：支持多币种，每个币种带金额与**报价有效期**；过期币种不可被接受。
3. **工程配置 configuration**：产生配置版本；客户与工程确认后成为签署版本。
4. **合规评审 compliance**：证书按目的国登记（CE、UL、原产地、结构认证等），访问需授权。
5. **采购 procurement**：对长周期/争抢模块先取得供应方的产能确认，再锁定并下单。
6. **投产与质检 production/qc**：投产即冻结配置版本；逐项质检，记录合格/让步接收/拒收。
7. **折叠装箱 folding/loading**：装柜即再次冻结；记录箱号与每座房屋的折叠尺寸/重量。
8. **海运 shipping**：支持分批发运、提单、到港；运输损伤在此阶段登记。
9. **展开验收 acceptance**：服务站现场展开，客户按签署版本**逐项核对**后签署。
10. **保修 warranty**：凭序列号发起工单，判定责任（供应/制造/运输/安装/客户）。

事件可以携带指向单据的引用（报价单号、变更单号、证书号、采购单号、箱号、提单号、工单号），
形成可交叉核对的连续记录，而不是彼此孤立的表格。

## 6. 配置变更规则

从一个配置版本到下一版本，变更影响单必须同时列出四个维度（缺一不可）：

- **受影响部件**：新增、移除、替换的模块/选项；
- **价格**：总价差额（各报价币种对应差额）；
- **重量**：总重变化；
- **交期**：最早可交日期的变化。

未列齐四要素的变更无效；变更在客户重新签署前不影响制造依据。

### 冻结与防静默切换

- **投产后**：批次数量及其配置版本固定。要改版本必须走"工程变更 + 双方重签 + 新批次/换版"的显式流程，
  系统拒绝把已投产数量静默指向另一版本。
- **装柜后**：箱内房屋的序列号与配置版本固定，禁止改版本或调换内容。

## 7. 产能锁定

- 供应方先确认**产能槽**（模块 + 时间窗 + 数量）。
- 订单在工程配置确认后对所需模块创建**产能锁**，锁数量从槽中扣减；槽位不得为负（不超卖）。
- 多张订单争抢同一模块时，以**已确认产能**为准分配，而不是以销售口头承诺为准。
- 订单取消/换版导致不再需要时，释放对应锁定。

## 8. 商务与合规

- **多币种报价**：一个报价可含多个币种，各自带金额与有效期；接受发生在有效期内才有效；
  汇率与币种不在系统内自动换算，以报价载明为准。
- **目的国证书访问**：证书登记适用国家与类型；查看/下载必须有授权记录（谁、何时、用途）。
  准入证书未通过评审的订单不得投产。

## 9. 物流与异常

- **分批发运**：一张订单可拆为多个发运批次，每个批次记录箱号、序列号清单与提单；
  全部批次到齐并验收后订单才完成。
- **检验不合格**：质检项判 `concession`（让步接收，需客户/工程批准）或 `reject`（拒收，需替换/返工）。
  存在未闭环不合格项的房屋不得装柜。
- **运输损伤**：在途/到港发现损伤，登记损伤事件、照片凭证与责任方，触发理赔与补发/维修。
- **许可延迟**：目的国进口/安装许可未就绪时，房屋到港入仓等待，记录滞留开始/结束与仓储责任，
  不改变序列号与配置版本。
- **断网安装回传**：现场无网络时允许离线采集：安装读数、照片、客户签署先落在终端，
  形成待同步事件（含本地签名指纹）；恢复网络后必须**同步回传并与对账单勾对**，
  所有离线事件回传前该发运批次不得标记验收完成。

## 10. 验收与保修

- 验收按签署版本的模块选项**逐项核对**实物，每项记录 `matched` / `defect`；
  全部匹配且无未闭环异常时客户方可签署，签署记录纳入事件链。
- 保修工单凭序列号发起，系统从事件链重现：所用选项版本、供应批次、质检结论、
  装箱/海运记录、安装与验收情况，据此判定责任归属并保留处理结论。

## 11. 不变量（由 `src/ledger.py` 强制）

1. 配置版本汇总价格/重量 = 选项明细之和。
2. 每次配置变更影响单必须齐列部件、价格、重量、交期四要素。
3. 投产后的批次数量与配置版本不得被静默改指；冻结点后的版本切换必须为显式换版事件。
4. 装柜后箱内序列号/版本固定。
5. 产能锁定总数不超过已确认槽位（不超卖）。
6. 接受报价必须在该币种报价有效期内。
7. 准入证书未通过评审不得投产；证书每次访问有授权留痕。
8. 未闭环质检不合格项的房屋不得装柜。
9. 离线安装事件必须在验收完成前完成回传勾对。
10. 验收逐项核对必须与签署版本一致才能通过。
11. 每个序列号都能从质检打刻到保修形成连续、按时间排序、责任明确的事件链。
12. 同一序列号不得被两座房屋重复使用，且必须归属且仅归属一个生产批次。
