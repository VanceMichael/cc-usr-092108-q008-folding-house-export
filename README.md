# 折叠房跨境配置交付

约定模块化房屋（双翼房、太空舱等）从询盘、工程配置、合规评审、采购、质检、折叠装箱、
海运、展开验收到保修的连续交付数据结构与业务不变量。

## 目录

| 路径 | 内容 |
| --- | --- |
| `docs/domain-model.md` | 领域模型：术语、参与者职责、端到端流程、配置变更/冻结/产能锁定/异常处理规则与 12 条不变量。 |
| `contracts/ledger.schema.json` | 交付台账 JSON Schema（模块/选项/配置版本/变更单/证书/产能/批次/序列号/装柜/分批发运/异常/断网回传/验收/保修/事件链）。 |
| `contracts/context.schema.json` | 简版领域上下文资料格式。 |
| `fixtures/ledger.json` | 贯穿全流程的虚构样例：德国双翼房订单 + 美国太空舱订单争抢同一二代中控产能。 |
| `fixtures/context.json` | 简版虚构样例。 |
| `src/context.py` | 简版上下文读取器。 |
| `src/ledger.py` | 台账结构校验、业务不变量检查与序列号追溯（零第三方依赖）。 |

## 样例覆盖的业务情形

- 多币种报价与报价有效期（过期币种不得被接受）；
- 配置版本 1→2 变更，影响单齐列**部件、价格、重量、交期**，客户与工程双签；
- **投产冻结**（批次数量/版本不得静默切换）与**装柜冻结**（箱内序列号/版本固定）；
- 两张订单争抢受限智能中控：Q2 槽位 6 套按已确认产能先锁先得，余单锁 Q3 并分两批发运；
- 目的国证书（CE/UL/IBC/原产地）评审通过方可投产，每次访问有授权留痕；
- 质检让步接收（折价）与拒收返工闭环后才放行装柜；
- 运输损伤理赔、施工许可延迟保税仓等待；
- 山口现场断网，离线采集签署 → 恢复后回传并与对账单勾对；
- 客户按签署版本逐项核对实物；
- 保修凭序列号重现制造到运维的每次决定与责任归属。

## 使用

校验台账：

```bash
python3 -m src.ledger fixtures/ledger.json
# 校验通过：2 张订单，7 座房屋，产能槽 3 个，事件链完整。
```

海外服务站扫描序列号，重现该房屋的制造配置与完整决定链：

```bash
python3 -m src.ledger fixtures/ledger.json --trace FH-DPX-0003
```

输出首行为实物配置快照（电气制式、防风抗震等级、内装、智能模块选项），其后为按时间排序、
带执行角色与决定人的事件链（打刻 → 质检 → 装柜 → 海运 → 回传 → 验收 → 保修）。

## 校验规则（摘要）

1. 配置版本汇总价格/重量必须等于选项明细之和；
2. 配置变更影响单必须齐列部件、价格、重量、交期，且差额与版本差值吻合；
3. 投产后批次数量与配置版本冻结，禁止静默改指；装柜后箱内序列号/版本冻结；
4. 有效产能锁定总数不得超过供应商已确认槽位（不超卖）；
5. 接受报价必须在该币种报价有效期内；
6. 准入证书未通过评审不得投产；证书访问必须有授权留痕；
7. 未闭环质检不合格项（让步/拒收）的房屋不得装柜；
8. 离线安装事件必须在验收完成前回传并勾对；
9. 验收逐项核对结果必须全部与签署版本选项一致；
10. 每个序列号全局唯一，拥有从质检打刻到保修、按时间排序且责任明确的事件链。

完整规则见 `docs/domain-model.md`，正例与每个反例见 `tests/test_ledger.py`。
