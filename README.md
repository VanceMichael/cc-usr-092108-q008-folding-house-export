# 折叠房跨境配置交付

约定模块化折叠房从询盘到保修的连续记录，使工厂与海外服务站都能从**序列号**重现每一次决定与责任归属。

## 要解决的问题

海外服务站扫描一台折叠房的序列号时，应当知道它的电气制式、防风抗震等级、内装与智能模块——而不是只查到销售最后一次改过的报价。本资料以双翼房、太空舱和虚构供应商/服务站为样例，打通九段记录并把关键约束固化为可执行规则。

## 九段连续记录

| 阶段 | 记录 |
| --- | --- |
| 询盘 | `inquiries`、`quotes`（多版本、多币种、有效期） |
| 工程配置 | `configuration_versions`（含电气制式/防风/抗震/内装/智能模块）、`config_changes`（ECN） |
| 合规评审 | `certificates`、服务站 `cert_access` 授权 |
| 采购 | `suppliers.confirmed_capacity`、`capacity_locks` |
| 质检 | `inspections`、`ncrs` |
| 折叠装箱 | `containers`（折叠核验、封条） |
| 海运 | `shipments`（分批、提单、到港状态） |
| 展开验收 | `permits`、`offline_install_records`、`installations`、`acceptance_checks`、`punch_items`、`damage_reports` |
| 保修 | `warranties` |

`production` 为每台房分配序列号并冻结配置；`events` 是跨全部阶段、带责任方的统一事件流。

## 固化的规则

- **变更影响**：ECN 必须列出受影响部件及价格、重量、交期差异；代码按配置版本复算并核对，错报即不通过。
- **版本冻结**：投产前可自由变更；投产后须客户书面批准；**装柜后一律拒绝换版**，数量不得静默切换。序列号冻结配置须由签署版本经已批准 ECN 衔接。
- **产能锁定**：多单争抢同一模块时，只按供应商**已确认**产能先后锁定（样例：7 月光伏 2 套被德国单锁定，美国单争抢被拒，待 8 月产能确认后才锁到）。
- **报价**：每个报价版本自带币种与有效期；订单锚定签署时版本，销售之后改价不追溯。
- **证书**：须覆盖目的国且在有效期内，仅授权服务站可访问。
- **质检放行**：终检/复验合格、NCR 装柜前关闭、折叠核验完成才允许入柜。
- **分批发运**：累计装柜数量须等于订单行数量，批次内不得串入其他订单序列号。
- **运输损伤**：封条完好 + 联合查验 → 归责承运人、索赔、换件复验闭环。
- **许可与断网**：送电不得早于许可批准；断网安装记录先存本地，回传时同号同内容去重、同号异内容隔离，绝不静默覆盖。
- **逐项验收**：客户对照冻结版本逐项核对，有未关闭不符项不得签收，签收后保修起算。

## 文件

- `contracts/records.schema.json` — 全链路记录的 JSON Schema 契约
- `fixtures/records.json` — 可公开使用的虚构样例（德国双翼房 2 台分两批 + 美国太空舱 1 台）
- `fixtures/context.json` — 领域参与者、事实与约束的摘要资料
- `src/records.py` — 装载、索引与参照完整性
- `src/configuration.py` — 变更影响复算与投产/装柜冻结
- `src/capacity.py` — 已确认产能锁定
- `src/delivery.py` — 报价、证书、质检放行、分批、损伤、许可、断网回传、逐项验收
- `src/timeline.py` — 序列号档案聚合与配置冻结链
- `src/scan.py` — 服务站扫码命令行入口

## 本地校验

```bash
python -m unittest discover -s tests    # 38 条规则测试
python -m src.scan SN-SYF20-002         # 扫码查看一台房的完整档案
```

样例中公司、人员、客户与单号全部虚构，不含真实个人信息、账号、密钥或连接凭据。
